# ScienceFound · 《毒与证》科学科普工作区

> 系列定位：生化武器（生物/化学武器）的科学与历史科普 · 目标发布平台：微信公众号 · 系列名《毒与证》
> 目录结构 2026-09-11 重建（迁移对照见 `docs/工程结构迁移记录.md`）。

## 目录结构

| 目录/文件 | 用途 |
|---|---|
| `正文/` | **所有科普正文稿**。状态直接写入文件名：`待发_`表示尚未发布；无此前缀表示已发布。章节局部编号：番外01/02、第01篇01–04、第02篇01–06、第03篇01–06 |
| `docs/` | 写作纪律与协议（00/33）、大纲与细纲（01/02/14）、素材与术语（08/12/16）、核验审查记录（15/23/30）、评估报告（31/32）、夜班记录、会话记忆、工具使用指南、封面_清单、研究摘记 |
| `封面/` | 全系列封面图（16:9，清单见 `docs/封面_清单.md`）＋提示词文件 |
| `知识库.md` | 已登记、已核验并可能进入正文的病原体与证据台账 |
| `未科普的病原体.md` | 因篇幅、路线或证据原因暂未进入正文的病原体登记表 |
| `.trash/` | 过时文档（试稿/旧修订稿/旧版说明），确认无用后可物理删除 |
| `.ignis-tools/` | ignis CLI 运行时（不入库） |

## 正文命名规则

- 已发布正文：保持现有章节文件名。
- 未发布正文：文件名以 `待发_` 开头。
- 发布完成后，只去掉文件名开头的 `待发_`，正文内容不因改名而改变。
- 发布状态以文件名为准，不在 README 中维护逐篇发布清单。

## 核心纪律速指

- 写作红线 / 证据分级 / 情绪护栏：`docs/00_项目协议.md`、`docs/33_正文书写纪律与审核流程.md`
- 术语中文优先规范：`docs/00_项目协议.md`（术语要求段）+ `docs/16_术语缩写对照表.md`
- 逐节细纲与核验路线：`docs/14_系列逐节细纲与知识路线.md`
- 病原体与证据台账：`知识库.md`（先登记、核验后进正文）
