## 目录结构

| 目录/文件 | 用途 |
|---|---|
| `正文/` | **所有科普正文稿**。状态直接写入文件名：`待发_`表示尚未发布；无此前缀表示已发布。命名：全篇统一为“主题词＋节号”（番外篇/实验室篇/炭疽篇/鼠疫篇/结核篇……，见下方“正文命名规则”） |
| `docs/` | 写作纪律与协议（00/33/61）、**两卷各自的大纲与细纲**（病原体卷 01/14，生化卷 84）、素材与术语（08/12/16）、核验审查记录、评估报告、夜班记录、会话记忆、工具指南 |
| `封面/` | 全系列封面图（16:9，清单见 `docs/封面_清单.md`）＋提示词文件 |
| `知识库.md` | 已登记、已核验并可能进入正文的病原体与证据台账 |
| `未科普的病原体.md` | 因篇幅、路线或证据原因暂未进入正文的病原体登记表 |
| `.trash/` | 过时文档（试稿/旧修订稿/旧版说明），确认无用后可物理删除 |
| `.ignis-tools/` | ignis CLI 运行时（不入库） |

## 正文命名规则

- 已发布正文：保持现有章节文件名。
- 未发布正文：文件名以 `待发_` 开头。
- 发布完成后，只去掉文件名开头的 `待发_`，正文内容不因改名而改变。
- 发布状态以文件名为准，不在 README 中维护逐篇发布清单。
