## 三、命名规则

**病原体卷**（`毒与证/`）：已发布，保持现有文件名，不动。

```
番外篇01_病毒与细菌_公众号发布稿.md
炭疽篇01_…_公众号发布稿.md
```

**生化卷**（`正文/`）：统一前缀，写作中不改名。

```
待发_生化卷_总篇01_毒的两条腿_公众号发布稿.md
待发_生化卷_日本03_哈尔滨的实验室王国_公众号发布稿.md
待发_生化卷_南非02_海岸计划_公众号发布稿.md
```

发布完成后，只去掉开头的 `待发_`。**发布状态以文件名为准**，不在 README 里维护逐篇发布清单。
