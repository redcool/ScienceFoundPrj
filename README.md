## 工具与联网搜索（2026-09 记录）

- 模型环境：本工作区会话由 DSH 驱动，模型走公司网关（OpenAI-completions 格式）：
  - LiteLLM：`https://litellm.funplus.com.cn`（默认 deepseek-v4-flash，凭据 `LITELLM_FUNPLUS_API_KEY`）
  - 未配置 `DEEPSEEK_API_KEY`，内置 `web-search-deepseek`（Anthropic 协议 + 原生 `web_search_20250305` 工具）**不可用**——公司网关不支持该协议/工具。
- 联网搜索通道：**simpleMCPServer 的 `web.search` 工具**（H:\ai_works\SimpleMcpServer，127.0.0.1:45678）。
  - 通道链（2026-09 已升级）：**Serper（Google API，已配 key，中文质量最好）→ google(无 key 跳过) → bing → ddg-html → ddg-lite**；Serper 有免费额度约 2500 次/月。
  - 调用：`POST /rpc` 直连 JSON-RPC，jsonrpc 2.0 + `tools/call` + `name:"web.search"` + `arguments:{query,maxResults}`。
  - **⚠️ 必须用 UTF-8 字节发送中文 body**（PowerShell 用 `[System.Text.Encoding]::UTF8.GetBytes($json)`），否则中文变 `???` 结果全废（详见 session_memory.md 坑清单）。
  - **中文检索/公众号查重：别用 web.search（DDG/Bing 中文差），用搜狗微信搜索** `weixin.sogou.com/weixin?type=2&query=...`（web_fetch 直连，已验证可靠）。
  - 状态判断：看 `H:\ai_works\SimpleMcpServer\server.log` 尾部的 `query="..." → N result(s) via serper`。
  - **原生工具注册限制**：SimpleMcpServer 使用旧版 SSE MCP，DSH 的 dsh-mcp-client 仅支持 stdio 与 streamable-http，暂不能注册成 `mcp__simple__web_search`；当前通过 run_code 内 `/rpc` 调用使用。
