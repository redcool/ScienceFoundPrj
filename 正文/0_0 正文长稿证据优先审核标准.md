# 0 系列正文长稿 · 证据优先审核标准

> **版本：** v1.0（2026-11-28）
> **适用：** `正文/` 目录下 0 系列总纲（0_1、0_2）与 1—21 国别长稿
> **效力：** 本目录内的审核判据以本标准为准。`docs/61_《毒与证》发布前审核规范.md` 的 **三.4 双重用途删除条款**在本目录停止作为删除依据，其功能由本标准第四节替代；61 号其余条款（医学边界、反污名、去 AI 味、互引规范、事实分层）继续适用。
> **建立依据：** 作者 2026-11-28 决定——数据必须保留；长稿不能套用公众号短稿标准；唯一原则是以证据为准。

---

## 一、唯一原则

**以证据为准。** 三条推论：

1. 有来源、条件写清的数字，**保留**。
2. 无来源的数字，不删也不留——**先查**；查不到，改写为范围，或标"资料不足"。
3. 来源与结论不符的，**改结论，不改来源**。

本标准不设"看到危险对象就删"的条款。一段内容去留，只看它是否经得起证据核验，不看它是否让人不适。

**判定顺序固定为：** 先核来源 → 再核口径 → 再核组合 → 最后才谈表述。任何一步都不能跳过去直接删。

---

## 二、三类内容，三种处理

| 类别 | 例子 | 处理 |
|---|---|---|
| **A 事实与数据** | 1915 年 168 吨氯气；吸入性炭疽动物模型 LD50 约 8,000 CFU；炭疽芽孢在土壤中可存活数十年 | **保留**。每个数字带六要素（第三节） |
| **B 解释与框架** | "四道门槛""四代演进""善恶双轨" | **保留**。必须自标"本文分析框架，非国际标准、非学界通说" |
| **C 操作信息** | 合成路线、培养步骤、序列、菌株构建、设备规格、投放方法、规避核查方法 | **唯一硬删项**。历史背景、非操作性风险解释、法律与治理不在此列 |

**边界说明：** 历史剂量、产量、反应器规模、粒径、毒性倍数属于 A，不属于 C。它们是历史记录，不是操作说明。把它们从正文删掉，读者只会失去判断"为什么偏偏是这几种病原体"的依据，现实风险一点没变。

**判断 C 类的唯一问法：** 照着这段文字，一个外行能不能多走一步？能，是 C；不能，是 A。

## 三、数据元：每个数字六要素

正文里的每个数字，必须能回答六个问题：

| 要素 | 要求 | 反例 |
|---|---|---|
| 来源 | 机构、论文、报告、档案，可追溯 | "有资料显示" |
| 年份 | 数据产生或发布年份 | 不给年份 |
| 对象 | 人、动物、细胞、模型、设施 | 把动物数据写成人类数据 |
| 模型或统计性质 | 实验值、估计值、模型值、抽样、上限/下限 | 把估计值写成实测值 |
| 单位与口径 | CFU、吨、微米、例、年 | 混用两套口径 |
| 适用范围 | 能推到哪、不能推到哪 | "普遍如此" |

**正文写法（短括注）：**

> 吸入性炭疽在动物模型中的估计致死剂量约为数千个菌落形成单位（Peters 等，2002；动物数据，不能直接外推人类）。

**完整条目**登记进同目录的 `-证.md` 台账，格式见文末数据卡模板。正文只放短括注，台账放全量来源。

**禁止：** 把不同来源、不同对象、不同年份的数字拼成一个因果句（61 号二.2 继续适用）。

## 四、数据与结论解耦（替代 61 号三.4）

数据保留，但**禁止把数据写成实施条件**。这是本标准唯一一条句式禁令。

**可以：**

- "历史上苏联与美国的生物武器计划曾达到数百公斤级产量，代价是数万人、数十年与国家级工业配套。"
- "吸入性炭疽在无抗生素年代病死率很高，现代治疗下显著下降。"
- "气溶胶在呼吸道的沉积取决于粒径、密度、呼吸方式和气道结构。"

**不可以：**

- "只要把颗粒控制在 1—5 微米，就能……"
- "达到 8,000 个芽孢即可……"
- "把发酵罐稍加改造就能……"

**分析依据（应作为论点写进正文，而不是靠删数字暗示）：**

武器化的真实瓶颈是组织、人员、经费、工业配套与持续保障，不是任何单一参数。日、美、苏三国的项目规模、失败率与终止原因都支持这一点。一个数字单独存在时不构成能力；一组数字被写成"达标清单"时才构成暗示。所以本标准管的是**句式**，不是**数值**。

**"黄金窗口"一类修辞：** 允许作为科普比喻，但必须紧跟一句限定——不存在单一阈值，真实沉积是粒径、密度、呼吸方式与气道结构的共同结果。数字保留，绝对句改掉。

**例外：** 若某段内容确实构成 C 类（照做能多走一步），整段删除，不适用本节。

## 五、事实分层与证据等级

沿用 61 号二.1 的五层，并与 0_1 第八章的 A/B 分级对齐：

| 层级 | 定义 | 正文写法 |
|---|---|---|
| 直接事实 | 原始档案、条约原文、官方报告、正式论文 | 直接陈述 |
| 研究结论 | 多项研究或权威综述支持 | "研究认为" |
| 估计 | 有模型或抽样，需写范围、年份、对象、来源 | "估计约……（口径）" |
| 争议 | 并列主要解释 | "一种解释是……另一种是……" |
| 未知 | 无法确认 | "目前无法确认" |

**分级纪律：**

1. 事件确定性与归因确定性**分开判**，不得合并成一个等级。
2. 附录表的分级必须与第八章定义**逐条对齐**。
3. "能力评估""条约状态""设施属性"另设一栏，不得塞进事件分级。
4. 表内不得出现自认"非第八章严格意义"的条目——出现即说明分级体系需要扩表，而不是加脚注。
5. 奖项、荣誉、机构所在地**不是证据**，不得作为分级依据。

## 六、来源与核实说明

- 每个单元（章或卷）末尾设 `## 资料来源与核实说明`。
- 只写：机构、文件/论文、日期、统计口径、适用范围、争议性质。
- 不写：审核意见、内部纪律、"待核""见内部记录""红线"。
- **正文不出现审核语。** 需要提示证据强度时，用读者语言——"目前只有单一来源""学界尚有争议""官方数字与研究者估算差距较大"——不用分级代号，不写"该案例应归入某子类"。

## 附录 B：读者版说明（可直接放入 0_1 第八章，约 400 字）

> **本书怎样使用数字**
>
> 本书会给出剂量、产量、粒径、伤亡人数这类数字。它们的作用是让读者理解事件的规模与后果，不是提供操作条件。每个数字都注明来源、年份、对象和适用范围；动物数据不写成人类数据，估计值不写成实测值，不同来源的数字不拼成一句话。
>
> 书中也会出现"四道门槛""四代演进"这类说法。它们是作者用来组织材料的分析框架，不是国际标准，也不是学界通说。
>
> 一个数字单独存在时不构成能力。真正的门槛是组织、人员、经费、工业配套和持续保障——这也是历史上那些国家级生物武器计划最终失败、终止或被销毁的原因。本书保留这些数字，是因为删掉它们，读者就无法判断"为什么偏偏是这几种病原体"，而不是因为它们在今天还有什么用处。
>
> 凡涉及具体操作的内容——合成路线、培养步骤、序列、设备规格、投放方法——本书一律不写。
