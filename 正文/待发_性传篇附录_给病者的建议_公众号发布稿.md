# 性传篇附录：给病者的建议

这一页清单，写给正在担心、正在治疗、或者替伴侣担心的读者。它不是诊断，也不是处方，只是一份"下一步做什么"的清单。

## 一、我可能感染了

**不要等症状。** 前面几节反复说过：多数性传播感染没有症状，有症状也不典型。

**时间很重要。** 不同病原体的检测窗口不同，太早查可能查不出来：

| 病原体 | 大致窗口 | 说明 |
| --- | --- | --- |
| HIV | 2—6 周，个别更长 | 第四代检测可缩短；高危后可按医生建议复测 |
| 梅毒 | 2—6 周 | 早期可能阴性，按医生安排复查 |
| 淋病、衣原体 | 1—2 周 | 核酸检测更敏感 |
| 乙肝 | 1—6 个月 | 查乙肝五项 |
| 丙肝 | 2—6 个月 | 抗体阳性后查核酸确认 |
| HPV、疱疹 | 无固定窗口 | 没有症状时检测意义有限，按医生判断 |

**去哪儿查。** 疾控中心的自愿咨询检测门诊、综合医院皮肤性病科、感染科、妇幼保健机构。检测可以匿名或实名，具体按当地规定。

**HIV 暴露后预防。** 如果发生了明确的高风险暴露，越早越好，通常要求在 72 小时内启动，并由医生评估和开药。千万不要拖。

## 二、我确诊了

1. **按医嘱治疗，把疗程走完。** 症状消失不等于治好，尤其是淋病、衣原体、支原体。
2. **按医生要求复查。** 复查时间和方法因病原体而异，有的要间隔几周。
3. **告诉伴侣，但不必独自承担。** 很多地方疾控和医院可以协助通知，不必自己开口。
4. **保护隐私。** 医疗机构对就医信息有保密义务；报告是给公共卫生统计用的，不是给单位或社区看的。
5. **别自己买药。** 剂量不足、疗程不够，是耐药和复发最常见的原因。

## 三、伴侣怎么办

- **同查同治。** 一方治好、一方没治，几乎一定会传回来。
- **不必互相追责。** 感染可能已经存在很久，谁传给谁往往无法确认；追责只会让人隐瞒，反而扩大传播。
- **一起面对。** 大多数性传播感染可以治好或控制，真正难的是开口那一步,自己给自己勇气。

## 四、去哪儿求助

| 需要 | 可以找 |
| --- | --- |
| 检测与咨询 | 疾控中心自愿咨询检测门诊、医院皮肤性病科 |
| 治疗 | 综合医院皮肤性病科、感染科、妇科、泌尿外科 |
| 孕期相关问题 | 妇幼保健机构、产科 |
| 心理压力 | 心理援助热线（全国统一号码 12356，以当地公布为准）、医院心理科 |
| 政策与法律咨询 | 当地卫生健康部门、法律援助机构 |

## 五、三句要说给所有人听的话

1. 感染不是道德判决。病原体不认人的品格，只认传播途径。
2. 检测不是审判。它只是把"看不见"变成"看得见"。
3. 治好之后，你仍然是你。慢性感染需要长期管理，但不影响一个人正常生活、工作和被爱。

## 资料来源与核实说明

1. **各类病原体的检测窗口**：现行检测规范与诊疗指南；窗口随试剂与方法变化，以医生判断为准。
2. **HIV 暴露后预防的 72 小时时限**：现行艾滋病诊疗指南与 WHO 相关建议。
3. **医疗机构对就医信息的保密义务**：现行《传染病防治法》与医师执业相关规定。
4. **疾控中心自愿咨询检测服务**：中国疾控中心公开信息，各地设置不同。
5. **心理援助热线**：全国统一心理援助热线号码以国家卫生健康部门公布为准。
6. **范围与适用边界**：本文是行动清单，不是诊断或处方；所有检测、用药与随访以医生评估和现行指南为准。
