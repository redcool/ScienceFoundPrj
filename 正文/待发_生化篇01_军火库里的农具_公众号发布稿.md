# 生化篇01：军火库里的"农具"

先问一个问题：如果要把病原体用于战争，历史计划最看重哪些特征？**在历史记录中曾被纳入生物武器计划的病原体，往往具有若干共同风险特征**——被描述为低感染剂量、在气溶胶中的稳定性、人群缺乏普遍免疫、发病后难以有效救治。一批病原体因为满足这些条件，在冷战军火库里被当成了"农具"。

## 一、为什么是"它们"：武器化的挑选逻辑

生物武器的核心形态之一，是**气溶胶**——把病原体做成能被吸入的微小颗粒。哪些风险特征被历史计划看重，谁就被盯上（以下均为定性描述，不涉及任何技术参数）：

- **环境稳定**：干燥、气溶胶中存活时间长（如炭疽芽孢，篇 2 详述）；
- **感染剂量低**：吸进去的颗粒越少越能致病（如土拉菌）；
- **传播与后果**：可人传人（如天花）、或可能造成长期消耗性后果（如布鲁氏菌的慢性病程）；
- **防控难**：无疫苗或疫苗覆盖不足、早期难识别、治疗代价高。

## 二、军火库里的"短名单"

苏联生物武器体系重点研制的病原体，公开资料与当事人证词指向大致稳定的一批（各病原体详细科学背景见各自专篇或资料段）：

| 病原体 | 为什么被选中 |
|---|---|
| 炭疽（芽孢） | 环境极稳定，可长期保持感染力（篇 2 已详） |
| 鼠疫（杆菌） | 致病性强、可人际传播（篇 3 已详） |
| 土拉菌 | 感染剂量极低、易气溶胶化，被称为"潜在的最典型气溶胶病原体"之一 |
| 布鲁氏菌 | 慢性、致残性高，可能造成长期消耗性后果（定性） |
| 马脑炎病毒（VEEV） | 气溶胶传染、人畜共患，可能同时影响人与动物（定性） |
| 天花病毒 | 高度传染、人群中已无普遍免疫（篇 5 的天花封存由此而来） |
| Q 热（贝氏柯克斯体） | 常被描述为感染剂量低、环境稳定性强（定性，各来源表述不一） |

清单反映的不是"毒性排名"，而是历史计划关注的共同风险特征（各病原体是否进入研制范围，以公开研究叙述为准）。

## 三、为什么这篇不写"怎么做"

本篇只讲"为什么选它们"，**不讲任何制备、培养、武器化或投放的方法**——不是回避历史，而是这类知识本身就是风险。理解"选择逻辑"已经足够读懂后面的制度故事。

## 四、收束：从"病原体名单"进入"帝国体制"

名单背后是一个完整的体系：庞大、伪装的科研生产网络，与一支看不见的"军队"。下一篇，我们看这个体系是怎么用"民用生物技术"的外壳运转起来的——Biopreparat。
