# 生化篇01：军火库里的农具

如果要给生物武器列一份"清单"，会发现它不长：炭疽、鼠疫、土拉菌、布鲁氏菌、马脑炎病毒、天花、Q 热。为什么是这几个名字，而不是别的？这一节讲挑选的逻辑，不讲制造的方法。

## 一、四条挑选标准

把病原体变成武器，历史上最看重的不是"毒性排名"，而是四件事。

**第一，能不能在空气里活下来。** 生物武器的主要形态是气溶胶——把病原体变成能被吸入的微小颗粒。颗粒在空气中漂着的时候，紫外线和干燥会杀死大部分微生物。炭疽的芽孢能扛住这一关，这是它排在第一位的根本原因。

**第二，吸进去多少才致病。** 有些病原体的感染剂量极低，几个到几十个菌落就能让人发病。这意味着同样的播撒量，能造成的暴露面大得多。土拉菌和 Q 热常被举为这一类。

**第三，人群有没有免疫力。** 天花在 1980 年被宣布消灭之后，全球停止常规接种。也就是说，四十多年过去，绝大多数人已经没有免疫力——这让一个已经被"消灭"的病毒重新具备了传播潜力。

**第四，好不好治、好不好防。** 有疫苗、有特效药、能早期识别的病，军事价值就低；反过来，慢性化、致残、难诊断，就容易被看上。布鲁氏菌属于这一类：它不常致死，但能让人长期丧失劳动能力。

## 二、军火库里的短名单

苏联体系的重点研制对象，公开资料与当事人陈述指向大致稳定的一批。

| 病原体 | 被选中的理由 |
| --- | --- |
| 炭疽（芽孢） | 环境极稳定，土壤里可存活数十年 |
| 鼠疫 | 致病性强，可人际传播 |
| 土拉菌 | 感染剂量极低，气溶胶稳定性好 |
| 布鲁氏菌 | 慢性、致残，长期消耗 |
| 马脑炎病毒 | 可气溶胶感染，人畜共患 |
| 天花病毒 | 人群已无普遍免疫 |
| Q 热 | 剂量低、环境稳定，诊断困难 |

这张表不是"毒性排行榜"。它反映的是同一套筛选逻辑：稳定、省量、难防、难治。

有一点必须说清：表中的病原体，在民用领域都有正当研究对象——炭疽是兽医和人兽共患病的重要课题，土拉菌是实验室感染的经典案例，Q 热是畜牧业和地方病的常见问题。**同一个病原体，放在不同目的下，是完全不同的两件事。** 这也是为什么后来核查"一个研究所在做什么"会那么困难。

## 三、为什么不写"怎么做"

这一节到此为止，不涉及培养、扩增、武器化与投放的任何方法。这不是回避历史——理解了挑选逻辑，已经足够读懂后面三节要讲的制度故事；而方法本身，写出来就是风险。

## 四、收尾

一份短名单，背后是一整套体系：谁来决定研究什么、谁来生产、谁来看守秘密。下一篇讲这个体系——苏联生物制品总局，西方后来称之为 Biopreparat。

## 资料来源与核实说明

1. **四个挑选维度（环境稳定性、感染剂量、人群免疫状态、防控难度）**：公开生物武器史研究的通行概括；本文只作定性描述，不涉及任何技术参数。
2. **短名单七项（炭疽、鼠疫、土拉菌、布鲁氏菌、马脑炎、天花、Q 热）**：公开历史研究与当事人陈述的交叉概括，不对应任何一份官方完整清单；具体项目以公开研究叙述为准。
3. **炭疽芽孢在土壤中长期存活、土拉菌与 Q 热感染剂量低、天花 1980 年后停止常规接种**：微生物学教材、WHO 天花消灭相关文件与病原学综述。
4. **各病原体的民用研究价值**：兽医与人兽共患病学教材通用口径。
5. **来源类型**：回忆录（Alibek & Handelman《生物危害》1999）、学术历史研究、BWC 官方文件、病原学通用资料四类，正文分别标注其性质。
6. **范围与适用边界**：一律不涉及制备、培养、武器化与投放方法；"农具""军火库"为叙事比喻，不是技术分类。
