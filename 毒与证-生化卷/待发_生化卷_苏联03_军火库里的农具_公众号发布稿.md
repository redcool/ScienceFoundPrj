# 生化卷·苏联03：军火库里的农具

如果要给生物武器列一份"清单"，会发现它不长：炭疽、鼠疫、土拉菌、布鲁氏菌、马脑炎病毒、天花、Q 热。这一节讲这几个名字是怎么挑出来的，不讲制造的方法。

## 一、四条挑选标准

把病原体变成武器，历史上最看重的不是"毒性排名"，而是四件事。

第一件是能不能在空气里活下来。生物武器的主要形态是气溶胶——把病原体变成能被吸入的微小颗粒。颗粒在空气中漂着的时候，紫外线和干燥会杀死大部分微生物。炭疽的芽孢能扛住这一关，这是它排在第一位的根本原因。

然后是吸进去多少才致病。有些病原体只要极少的量就能让人发病。同样的播撒量，能造成的暴露面就大得多。土拉菌和 Q 热常被举为这一类。

再往后是人群有没有免疫力。1980 年天花被宣布消灭，全球停止常规接种。四十多年过去，绝大多数人已经没有免疫力——一个已经被"消灭"的病毒，重新具备了传播潜力。

最后一件事：好不好治、好不好防。有疫苗、有特效药、能早期识别的病，军事价值就低；反过来，慢性化、致残、难诊断，就容易被看上。布鲁氏菌属于这一类，它不常致死，但能让人长期丧失劳动能力。

## 二、军火库里的短名单

苏联体系的重点研制对象，公开资料与当事人陈述指向大致稳定的一批。

| 病原体 | 被选中的理由 |
| --- | --- |
| 炭疽（芽孢） | 环境极稳定，土壤里可存活数十年 |
| 鼠疫 | 致病性强，可人际传播 |
| 土拉菌 | 感染剂量极低，气溶胶稳定性好 |
| 布鲁氏菌 | 慢性、致残，长期消耗 |
| 马脑炎病毒 | 可气溶胶感染，人畜共患 |
| 天花病毒 | 人群已无普遍免疫 |
| Q 热 | 剂量低、环境稳定，诊断困难 |

这张表不是"毒性排行榜"。它反映的是同一套筛选逻辑：稳定、省量、难防、难治。

表里有两个名字，一般读者不熟。Q 热是一种由柯克斯体引起的发热病，感染剂量极低，常被当成"不明原因发热"，畜牧业地区并不罕见。马脑炎是一类由蚊子传播的病毒性脑炎，也能经气溶胶感染，人畜共患。

有一点必须说清：表中的病原体，在民用领域都有正当研究对象——炭疽是兽医和人兽共患病的重要课题，土拉菌是实验室感染的经典案例，Q 热是畜牧业和地方病的常见问题。同一个病原体，放在不同目的下，是完全不同的两件事。这也是为什么后来核查"一个研究所在做什么"会那么困难。

## 三、为什么不写"怎么做"

这一节到此为止，不涉及培养、扩增、武器化与投放的任何方法。这不是回避历史——理解了挑选逻辑，已经足够读懂后面几节要讲的制度故事；而方法本身，写出来就是风险。

## 四、收尾

下一节讲这个体系是怎么建起来的：从 1972 年签约，到 1973 年建局。

**事实边界**：四条挑选标准是公开生物武器史研究的通行概括，不是苏联官方文件的原文；短名单七项来自公开研究与当事人陈述的交叉，不对应任何一份完整清单；炭疽芽孢在土壤中长期存活、天花 1980 年后停止常规接种，属病原学与公共卫生史可查事实。

## 资料来源与核实说明

1. **四个挑选维度（环境稳定性、感染剂量、人群免疫状态、防控难度）**：公开生物武器史研究的通行概括；本文只作定性描述，不涉及任何技术参数。
2. **短名单七项（炭疽、鼠疫、土拉菌、布鲁氏菌、马脑炎、天花、Q 热）**：公开历史研究与当事人陈述的交叉概括，不对应任何一份官方完整清单。
3. **炭疽芽孢在土壤中长期存活、土拉菌与 Q 热感染剂量低、天花 1980 年后停止常规接种**：微生物学教材、WHO 天花消灭相关文件与病原学综述。
4. **各病原体的民用研究价值**：兽医与人兽共患病学教材通用口径。
5. **来源类型**：回忆录（Alibek & Handelman《生物危害》1999）、学术历史研究、公约官方文件、病原学通用资料四类，正文分别标注其性质。
6. **范围与适用边界**：一律不涉及制备、培养、武器化与投放方法；"农具""军火库"为叙事比喻，不是技术分类。
