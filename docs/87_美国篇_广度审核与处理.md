## 四、结构问题（这轮最要紧的一类）

**美国 03 有两个"四"，其中一个是空节。**

原文结构是：三、不只是细菌 → **四、这几件事的共同点（空）** → **五、这几件事的共同点（有内容）** → **五、收尾**。读者会看到两个"四"、两个"五"，中间夹一个空标题。

处理：删掉空节，编号回到 一—五；并把这一节里误插的"越南／落叶剂"内容移走——03 讲的是三件模拟释放（旧金山、地铁、放蚊子），越战橙剂属于 04，混进来会让读者以为橙剂也是模拟试验。

改后的收束句："三件事都是模拟：用的细菌不致病，放的蚊子不带病原体。真正带毒的那一类，是下一篇的橙剂——但它是化学落叶剂，和生物战剂不是一件事，放在一起讲会含混。"
