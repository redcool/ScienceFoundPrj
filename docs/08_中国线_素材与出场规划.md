# 08_中国线_素材与出场规划

> 用途：系统挖掘中国病毒防治事件（**苦难与成就并重，1:1 平衡**——见到苦难也要见到成就与坚持，否则读者与作者内心都无法平衡，呼应 00 协议第三节情绪护栏），规划出场顺序并入 01_系列大纲。
> 原则：中国线**不单独成篇**，作为各篇的"当代钩子 / 对照位 / 收尾位"嵌入；素材卡的事实标证据层级，"待核验"项核实后才能进正文。

---

## 一、规划原则

1. **平衡律**：每个"苦难/黑暗"素材必须配一个"成就/坚持"素材（1:1），用于正文与读者心绪的结构配比。
2. **不硬塞**：某篇无自然中国位则不强行插入；有的篇给一句"同期的中国在做什么"，有的篇给一整段对照。
3. **当代优先**：中国事实优先用作**当代钩子**（读者身边的人与事），历史身子保持世界主线。
4. **敏感护栏**：SARS、731、新冠疫情等素材——写事实、写制度教训、写人的坚持，不写归因与情绪引爆；敏感素材发布前须复核措辞。

## 四、风险与护栏（写入文件即生效）

1. SARS/新冠疫情素材：只写"事实 + 制度教训 + 人的坚持"，不写归因、不渲染；发布前复核措辞。
2. 731 篇：受害方视角 + 战后交易事实，避免民族情绪引爆（协议：不谴责、不赞美任何组织，对群体不作整体归因）。
3. 每个插入位都保持"正文 B 级"+"证据注释集中"格式统一。
