# 系列写作地图：《毒与证》（番外 2 节 + 20 篇；第1—3篇正文不动）

> 用法：本文件是**方向与目标**。动笔任何一节前，先看本节主题句与叙事主角；要调整路线（改主题、换顺序、删减素材），**先改这份大纲**，再动正文。节 = 公众号发布单元（约 2000 字）。

## 写作纪律（写进大纲，作为纪律）

6. **深渊与希望并写**：每节可以把危险讲深，但收尾必须指出可验证的希望方向——预防、治疗、康复、救援、制度改进或个人行动。不得用“没事的”粉饰，也不得用宿命论封死出口。
7. **扩充认知地图**：不把复杂事实压缩成一个口号；明确区分病原体/毒物、感染/发病、相关/因果、风险/现实概率、长期管理/终身绝望。
8. **术语中文优先**：正文本体面向国人读者。专业缩写首次出现统一写作“中文全称（英文全称，英文缩写）”（如 慢性消耗病（chronic wasting disease，CWD）），后文只用中文；HIV/DNA/mRNA/WHO/CDC/SARS/N95 等本土化缩写例外通行。规范细则见 `00_项目协议.md`；全系列缩写唯一口径查 `16_术语缩写对照表.md`。

1. **大纲先行**：调整路线 → 先改本文件 → 再写正文；不许边写边改方向。
2. **节 = 发布单元**：每节独立成文、独立标题、独立"资料来源与核实说明"，篇内节与节有衔接钩子；篇与篇可独立阅读。
3. **当代负责打动，历史负责扎实**：每篇第 1 节以当代钩子开场（普通人见过的事物），历史身子严格落证据层级。
4. **重复素材分工**：同一事件被多篇使用（如伯明翰、斯维尔德洛夫斯克、1894 香港鼠疫）时，以本篇的**侧重点**区分，正文避免整段复用，并互相引用"详见第 X 篇"。
5. **人物/故事优先（本系列灵魂）**：每篇设一名**叙事主角**（或一条人物故事线），科普知识通过人物的眼睛、经历、抉择自然带出——**毒**（病原体）与**证**（人用证据搏斗的过程）双线交织。禁止干巴巴罗列知识点；写作时自问："读者会记得这个人做过什么，而不是背结论。"
