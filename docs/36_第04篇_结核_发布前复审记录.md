# 第4篇《结核》发布前复审记录（2026-09-16）

> 审核对象：正文/待发_结核篇01—05；参考 docs/35、docs/33、docs/14。

## 一、总体判定

**篇级判定：有条件通过，先完成定点修订，再进入作者终审。**

五节结构成立：当代症状钩子 → 白色瘟疫社会史 → 科赫与链霉素 → 中国防治史 → 今天、潜伏感染与耐药。故事线、团队线、希望出口和安全红线总体合格。

## 二、必须修订

### 1. 标题和链霉素表述
第3节标题“科赫1882与第一个特效药”容易误解为人类第一种抗生素或可单药解决结核。建议改为“从科赫1882到第一种有效的抗结核抗生素”或“从看见结核杆菌到链霉素”。正文统一写“链霉素是第一种有效的抗结核抗生素之一/第一种有效抗结核抗生素”，并补充现代治疗依赖按指南联合用药，不能自行使用链霉素。

### 2. 发布日动态数据
第4、5节的WHO 2021—2023估算、2022年中国病例和“中低流行”判断必须在发布当天重新核对WHO最新《全球结核病报告》、中国疾控和国家卫健系统数据。正文数字保留年份、估算性质、病例定义；“排第三”“中低流行”必须找到原文依据，否则改为“报告显示相关指标下降”。

### 3. “咳嗽两周”不是诊断门槛
第1节“去定点医院排查”方向正确，但应补：
> 咳嗽两周是公共卫生筛查提示，不是排除结核的硬门槛；咯血、持续发热、明显消瘦、密切接触或高风险人群应按症状尽快就医。
“普通感冒和流感一周左右自愈”建议改为“许多普通感冒会逐步缓解”。

### 4. DOTS不能简化为盯着吃药
DOTS是公共卫生策略，包含规范联合治疗、药物供应、随访、依从性支持和必要时直接观察，不等于每次服药都由医务人员现场监督。建议改写，避免把患者写成被动监管对象。

### 5. 免费诊疗需限定
“胸片、痰检和一线药物都列入免费范围”需改为：中国部分公共卫生项目和定点机构为符合条件者提供免费或减免的筛查、诊疗和药物，具体以当地最新政策为准。

### 6. BCG避免绝对句
“每一个中国婴儿出生后，都要接种一针”改为：卡介苗纳入国家免疫规划，通常在出生后尽早接种，具体时间和禁忌按现行免疫程序及接种机构评估。

## 三、分节审核

### 第1节
病原体、空气传播、潜伏感染与活动性疾病、就医边界和RSV对照安排合理。需收紧“飞沫核比头发丝细”、消毒剂绝对表述和“抽烟都会”因果；全球四分之一估算保留年份。

### 第2节
古代证据、工业城市、文学史、牛奶卫生和疗养院路线成立。把“结核病是牛奶巴氏消毒的推手”改为牛结核和食品卫生风险是推动因素之一；文学人物死因继续使用传记或史料限定。

### 第3节
科赫、结核素、沙茨—Bugie—瓦克斯曼、MRC试验和诺奖争议线完整。需删减无法核验的“医学界一半大人物”“沉默几秒”；说明科赫法则是后人总结；MRC结果不要只写决定性成功，也提示耐药和毒性限制。

### 第4节
中国线、BCG、防治体系、流调和当代负担有价值。删除DOTS重复句；鲁迅和萧红死因保持保守；政策和“中低流行”需发布日核验。

### 第5节
BCG边界、潜伏感染、耐药、个人行动和2035目标闭合。潜伏感染不是患病或天然传染源；预防性治疗须由专业机构评估；疗程须写“遵照医生方案”，WHO目标保留相对2015基线。
