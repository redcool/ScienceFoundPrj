# 第8篇《霍乱》发布前复审记录（2026-09-20）

> 审核对象：正文/待发_霍乱篇01—04；参考 docs/43 证据卡、docs/33 正文纪律、docs/14 细纲。
> 复审重点：补液与就医边界、斯诺证据的历史准确性、中国O139与高守一贡献、全球动态数据、疫苗与WASH表述。

## 一、总体判定

**篇级判定：有条件通过，完成定点修订和发布日前动态数据复核后，可进入作者终审。**

四节结构成立：病原与补液 → 宽街水泵与流行病学证 → 中国流行与高守一 → 全球疫情、疫苗和WASH。无需重构；未发现培养、扩散或其他危险操作信息。

## 二、高优先级修订

### 1. 补液数字不能变成自行处理暗示
第1节的“50%上下”与“1%以下”应保留WHO口径、重症/未治疗条件和及时专业治疗条件。建议补一句：
> 大量水样腹泻、反复呕吐、明显口渴、尿量减少、头晕或意识改变，都需要尽快寻求医疗帮助；口服补液盐必须按包装或医务人员指导配制，重症患者不能只靠自行饮水。
“同一个病，两种结局之间只隔着一袋口服补液盐”建议改为“及时、正确的补液和医疗支持，可能显著改变结局”，避免忽略静脉补液、监测和专业救治。

### 2. “口服补液盐兑水就能救回大多数人”需限条件
ORS是关键工具，但“兑水喝下去就能把大多数病人的命拉回来”可能被理解为家庭自行治疗。应明确：能饮水且无重症表现者可在就医途中按正规说明补液；重症、持续呕吐、休克或意识改变需医疗机构静脉补液和监测。不要写配方比例。

### 3. 宽街水泵故事避免单因果和英雄化
“疫情随之平息”不能证明拆把手单独终止疫情；应写为“拆除把手成为阻断暴露的措施之一，暴发随后回落，但病例下降还受疫情自然进程、其他供水和公共卫生因素影响”。
“第一次用地图抓住霍乱”建议改为“用地图追踪传播线索”，避免“第一次”高风险。

### 4. 全球病例数字与“大流行”定义要更新
第4节“霍乱正处在一场持续多年的大流行里”容易与历史“第七次大流行”混淆，也不一定是WHO正式分类。建议改为：
> 全球霍乱疫情在近年持续扩大或反复暴发，多个地区同时受到影响。
发布前重新核对WHO最新年报和疫情通报；2022—2024数字必须带“报告病例”口径，不能当作全球真实感染总数。

### 5. 高守一与O139贡献需要原始来源复核
高守一的履历、机构归属、1993新疆O139病例和“团队完成病原鉴定/分子追查”是本篇中国线的核心。发布前需补原始论文或中国疾控/权威档案，并区分：
- O139首次发现与命名；
- 中国新疆暴发的病例调查；
- 病原鉴定；
- 分子流行病学追踪；
- 高守一本人、团队和监测体系的具体贡献。
“中国第一次正式抓住这个新病原”建议改为“完成了对该暴发病原的鉴定和追踪”，除非能明确“第一次”的定义。

## 三、分节审核

### 第1节：一桶水里的杀手
病原体、毒素、脱水与补液核心讲得清楚。需收紧：
- “短时间排出以升计”保留量级比喻，不要当作固定临床数字；
- “几个小时到几天”应与病情差异和就医边界配套；
- ORS不是所有患者的完整治疗，抗生素是否使用要由专业人员按病情和指南决定；
- 补液说明要加入何时就医，不给读者自行诊断或延误就医暗示；
- 病死率数字带条件，避免把未经治疗的重症与及时治疗的所有病例直接对比。

### 第2节：斯诺与宽街水泵
证据边界是本篇最强部分：斯诺负责传播途径证，科赫负责后续病原学证，帕西尼作为更早观察者出现。需：
- “几百米见方”与“十天数百人”保留来源和统计口径；
- “许多家庭一夜之间整户清零”是高情绪化概括，建议改为“部分家庭在短期内连续出现死亡”；
- “霍乱一定从口进入”改为“证据支持经口摄入传播”；
- 啤酒厂工人和水泵距离对照不是单一因果证明；
- 拆把手是委员会决定，拆除与疫情回落不是简单因果；
- 斯诺不是“第一次抓住霍乱”，而是重要的流行病学证据节点。

### 第3节：中国流行与高守一
团队化处理已经到位。需：
- “全球七次大流行”按WHO/史学口径说明，避免把“七次”当无争议的自然分类；
- “前几次都波及中国”“沿海省份轮番告急，肠道门诊一年开门半年”需有来源，或改成较克制的历史概括；
- O139首次发现地、日期、1993新疆暴发和高守一团队分工逐项核对；
- “近些年个位数到几十”必须注明是报告病例量级，不等同真实感染数；
- 2024年7月5例是单月数据，不宜作为年度状态的唯一例证；应补近年年度趋势或明确“单月例证”；
- “一旦饮用水卫生出问题，它随时可能抬头”改为“在饮水和卫生条件受损、输入或局部传播发生时，风险可能上升”。

### 第4节：今天与未来
有明确工具箱，但要：
- 删除或改写“持续多年的大流行”，避免与第七次大流行概念混淆；
- “一年比一年高”只能在同一WHO报告口径和连续年份成立时使用；
- 也门“数百万人规模”标明是疑似病例/报告病例或累计疫情估计；
- ICG单剂策略明确是特定供应短缺时期的临时策略，不是所有人都适用的接种方案；
- Dukoral、Shanchol、Euvichol产品状态和WHO预认证按发布日核对；
- 气候变化是风险放大因素之一，不写成单一直接原因；
- “最容易防的病之一”“一口脏水就截住”改为“传播链条中有多个可干预环节，但需要水卫生、疫苗、监测和医疗系统共同作用”。

## 四、结构、伦理与安全审核

### 已通过
- 四节路线清楚，补液—流行病学—中国监测—全球治理闭合；
- 斯诺、科赫、帕西尼、高守一和公共卫生体系的角色边界总体清晰；
- 没有把中国疫情归咎于单一群体或地区；
- 没有把霍乱写成“只要喝脏水就必然感染”；
- 未提供病原培养、毒素制备或扩散操作细节。

### 必须保持
- 补液优先，但不能把文章写成家庭治疗指南；
- 口服补液盐不等于所有重症都能自行处理；
- 霍乱病死率、全球病例、疫苗供应和中国病例必须带定义与年份；
- 中国“控制为极低水平”不等于消灭；
- WASH、监测、疫苗和临床治疗必须作为系统合力呈现。
