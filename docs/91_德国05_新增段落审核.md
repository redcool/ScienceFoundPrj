2. L25／L63—64 新增断言全部未落条目：事实边界（L100）与资料来源（L104—110）既无 Kulmhof 德名与"首个"之说，也完全没有"加拿大"仓库区一条（营房座数、一区二区、Kanada Kommando）。违"新增内容必须落到资料条目"与规范二.0。
3. L63 "最初有几十座木制营房专门用作仓库"——数字无口径：无年份、无统计对象、无来源；"最初"与下文"一区""二区"的先后也没交代（规范二.2）。
4. L64 "救活了不少同伴"——无来源的数量与因果断言；同句"偷拿…就会被处死""黑市交换"同样无出典。要么补来源，要么降为"据幸存者回忆"（规范二.1、二.3）。

## 三、B 级

2. L64 "特遣队""加拿大分遣队"——L57 已把"特别工作队（Sonderkommando）"定为唯一叫法；此处"特遣队"指 Kanada Kommando，两个不同单位共用一个词根，必然混读（规范四.2）。

5. L25 "波兰北部维斯瓦河畔另有一座同名城镇"——只否认同名城镇，没给营地在哪（波兰中部、内雷姆河畔的海乌姆诺-纳德-内雷姆村）。读者反而更容易把营地安到维斯瓦河边；且营地德语名 Kulmhof 与城镇旧名 Kulm 只差词尾，越注越糊。

## 二、改了什么

### A 级四处

1. **L25 事实错。** 原文"首个使用毒气进行大规模屠杀的固定设施"——海乌姆诺用的是毒气车，固定毒气室在奥斯维辛；且与本篇 L31"于是有了下一个方案：固定的毒气室"直接打架。改为："它是纳粹第一座开始运转的灭绝营——不是第一间固定毒气室。固定房间要到奥斯维辛。"
2. **地名括注重写。** 原文一处叠两个外文括注、再加"（注：……）"双层括号，且只说"不在维斯瓦河畔"，没说营地在哪。改为："波兰中部的海乌姆诺（Chełmno nad Nerem，德语称库尔姆霍夫 Kulmhof）"，把位置、德文名一次给清；"首座灭绝营"的说法进了事实边界与资料条目。
3. **"加拿大"块补来源。** 事实边界新增：一区 1942（主营）、二区 1943（比克瑙，约三十座木制营房）、Kanada Kommando 与特别工作队是两个单位。资料来源新增两条（纪念馆研究与幸存者回忆；海乌姆诺位置与德文名）。
4. **"救活了不少同伴"降级。** 改为"据幸存者回忆……有人靠这个活了下来"，并保留"偷拿被发现会被处死"，不写成"好差事"。
