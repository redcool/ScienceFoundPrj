# 生化总篇（篇 15）细节审核与加厚记录

日期：2026-10-12　范围：`正文/待发_生化卷_总篇01–07`

## 一、审核口径

沿用德国篇的标准：读者有基础逻辑能力，对生化科技缺乏常识；凡专有名词、机构、程序、分级，都要解释"是什么、为什么是这样"。总篇是全卷入口，标准比各国篇更严——它要给读者装零件，不是给读者结论。

## 二、硬错误（已改）

1. 01 结尾"病原体会造成感染,持续造成死亡"：半角逗号，句义重复。改为化学毒剂杀人于当下、病原体把死亡拉长。
2. 03 正文与"## 1915 与 1925"之间缺空行，Markdown 渲染会把该标题当正文。
3. 03 结尾"三样东西：能力、事故、谎言"——本节未出现任何"事故"，与内容不符。改为"能力、隐瞒，和一批没有被追究的人"。
4. 05 三处书名号与简称之间缺逗号；"《1925年日内瓦议定书》"未按体例排为"1925 年"。
5. 07 表"高峰"一列对中国不成立（原文填"1950 年代防御体系建设"）。改为"1930—1940 年代受害最烈；1950 年代建成防疫体系"。
6. 03、04 小标题为年份式无序号，与其余五节体例不一，已统一为"## 一、……"。

## 四、程序解释（"那一纸是什么"）

1. **02**："只隔一纸决定"补三个实例——1969-11-25 尼克松声明、1956 年英国内阁与国防委员会程序、1992 年 4 月叶利钦总统令；落到"决定是人做的，做决定的人有名字"。
2. **05**：把"能进门"拆成五步——申报、核查、封存、销毁、再核实；并点明生物那份文件只有第一句"我承诺不发展"，没有第二句"你来查"。
3. **04**：补"为什么挪进民用体系更安全"——军事体系被卫星、预算、议会盯着，民用部委不这样，换个牌子就不在军控视野里。
4. **05**：补"自愿透明"的定义——各国每年自愿提交信任措施报告，交不交、写多少全凭自愿。
