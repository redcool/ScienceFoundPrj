## 二、核对无误的事实

- 波顿当 1916 年设化学战实验站，1940 年设生物部，同年成立生物战委员会。
- 1942 年英美加三方技术交流、1943 年德特里克营建立。
- 格鲁伊纳岛不到两平方公里；1942 年绵羊试验；"素食者"计划未实施；1986—1990 年去污，1990 年宣布清除并交还业主。
- 1981 年"黑收获"取土送至波顿当门口；五年后（1986）开始去污。
- 1950 年代伦敦地铁北线释放枯草杆菌变种（Bacillus globigii），痕迹在约十六公里外检出；实验未告知乘客；1990 年代公开，国防部承认但未道歉。
- 1956 年放弃进攻性计划，1957 年国防白皮书确认；1972 年签署 BWC、1976 年批准；波顿当现为 Dstl。

## 三、仍可加密（未改）

1. **01 §二 三方技术交流缺具体内容**。原文只有"1942 年建立三方技术交流"，没说交流了什么、谁去谁那里。若能补一句（交换的是试验数据与安全规程，还是具体菌株与弹药设计），这一节的分量会不同。此条在上一轮英国审核时已列入待补文献，至今未补。
2. **02 §三 去污用量**。"消毒液以千吨计"区间太宽，若有官方工程量数字（吨数、面积、工期），比"千吨计"更有说服力。
3. **03 §一 为什么选枯草杆菌**。原文说"芽孢大小、气溶胶行为与炭疽接近，但不会致病"，还可以补一句它现在的分类名（Bacillus atrophaeus），说明这个"无害替代品"的判断后来也被修正过。
4. **04 §一 第三层"政治"**只有一句"议会里也有人追问"，没有具体人、具体质询。这是全篇最薄的一段。
