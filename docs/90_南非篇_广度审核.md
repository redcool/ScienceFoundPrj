# 主笔处理记录

## 一、A 级：三类问题

### 1. 把未经司法认定的材料写成定论（5 处）

这是本篇最要命的一类。南非的材料大量来自 TRC 证词与调查报道，很多指控从未定罪。原稿有几处直接写成了事实：

- "据后来的调查，西明顿还从大学里秘密招募过医学与兽医学生做志愿者，早期就有过人体毒性试验。" → 补"这一条属调查与指控层级，未见完整档案"。
- "把霍乱弧菌投进莫桑比克境内的河流与游击队营地的水源" → 改为"据研究者与津巴布韦政府后来的判断"。
- "寻找只对黑人起作用的生物手段" → 前加"据 TRC 记录"。
- "项目内部也有人被处理" → 前加"据证词"。
- 04 篇"人体实验、跨境暗杀、生物投毒，一条条摆出来" → 明确是"听证会上提出的指控"。

### 2. 触红线：投毒载体与投放路径（4 处）

- "把对硫磷浸进衣服、内衣、制服" → "让剧毒有机磷农药浸进衣物"，去掉做法细节。
- "罐头、饮料、香烟，以及抗生素这类医疗用品，往里加铊" → "食品、饮料、香烟，以及抗生素这类医疗用品，都被掺进了铊"，去掉逐项清单式写法。
- "用飞机投放炭疽芽孢" → "从空中把炭疽芽孢撒向牧区"，并补"这一条是研究者的判断，未经司法认定"。
- "载体做得像日用品——雨伞尖、巧克力、香烟、衣服" → "这些东西被做成了日用品的样子"。

判断标准还是那一条：**"用过这些载体"是史实，"载体怎么做"不是。** 清单列得越细，越接近操作手册。

### 3. 替法院下结论（3 处）

- "理由不是'事情没发生'，而是：多数行为发生在南非境外" → 前加"法庭给出的主要理由"。
- "这个判决说的是前者" → "按判决书，它说的是前者"。
- "理由是技术性的：证据不足" → "裁定的理由是技术性的"。

## 二、B 级改了十处

"打了十五年的丛林战争" → "从 1965 年打到 1980 年"；"数万人感染" → "研究估计上万人感染"（Cross 的口径）；"与 1500—2500 名死亡有关" → "估计造成……死亡"；"第二年，一个心脏病专家被招进来" → "1981 年底到 1983 年间"；"1989 年……他决定停掉" → "上台后逐步停掉"；"它证明了一件事" → "它至少说明了一件事"；"它在做的时候就已经在为将来没法审做准备" → "客观上让追诉变困难；是不是当年的设计，没有档案能证明，但从结果看效果一样"；"TRC 的档案比很多国家都完整" → "相当完整"；"几乎没造出能用的战场武器" → 前加"从公开记录看"。
