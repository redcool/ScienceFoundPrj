# 第 5 篇《天花：被消灭的第一个病毒》证据卡（2026-09-16 建）

> 对应 14 细纲"篇 5 天花（7 节）"；叙事主角：帕克（最后死者）＋詹纳（第一个疫苗）；"无药有疫苗"。
> 34 插入对象：麻疹/风疹/腮腺炎（疫苗可预防病、群体免疫、免疫空白）、猴痘（正痘家族收束）、水痘—带状疱疹（短提示）。
