# 第7篇《流感与新冠》发布前复审记录（2026-09-16）

> 审核对象：正文/待发_流感与新冠篇01—07；参考 docs/41 证据卡、docs/33 正文纪律、docs/14 细纲。
> 复审重点：流感与冠状病毒概念边界、1918/2009/2020时间线、样本伦理、当代新冠与禽流感动态数据、医学安全和因果表述。

## 一、总体判定

**篇级判定：有条件通过，但不建议原样发布；完成动态数据、疫情因果和医学术语的定点修订后，进入作者终审。**

七节结构成立：季节性流感地图 → 1918费城 → 1918基因组 → 2009 H1N1 → 冠状病毒家族 → 新冠进行时 → 大流行准备清单。主线清楚，未发现需要重构的问题，也未发现危险操作内容。

## 二、高优先级问题

### 1. 发布日动态数据必须更新
第1、5、6、7节使用流感负担、MERS、新冠变株、长新冠、H5N1人病例和奶牛疫情数据。所有这些都必须按发布日重新核对WHO、CDC、中国疾控、FDA/MHRA等来源，并保留年份、地区、病例定义和数据截止日。尤其不要把2026年证据卡中的动态数字直接当作永久事实。

### 2. 新冠溯源表述不能写成封闭结论
第6节“很可能源于自然界跨种溢出、没有任何可信证据支持实验室起源”过于绝对，也与当前科学和机构评估中“证据仍不完整、不同假说证据权重不同”的表达不完全兼容。建议改为：
> 现有公开证据支持自然跨种溢出是重要解释，但溯源研究仍有未解问题；本文不把未经证实的假说写成定论，也不进行个体指责。
这样既不写阴谋论，也不把科学问题提前封死。

### 3. “测序”与“重建”需区分
第3节“重建出了1918流感病毒近乎完整的基因组序列”容易被误读为重建活病毒。建议统一写“从历史样本中拼接并推断出近乎完整的基因组序列”，并保留“不是复活病毒”的安全澄清。第6节“几周内读懂病毒”也应改为“完成基因组测序并共享”，避免把测序等同于已经理解全部生物学性质。

### 4. 不要把2009疫苗写成单纯“输给时间”
第4节“疫苗第一次在全球尺度上输给时间”有传播力，但可能掩盖生产、审批、推荐、分配和需求预测等多重因素。建议改为：
> 2009年疫苗产能和分配启动晚于疫情扩散，暴露出从候选株确定到生产和接种之间的时间瓶颈。

### 5. H5N1“头号种子”和“全球首次大规模奶牛版”需收紧
“头号种子”是作者比喻，必须明确不是风险排名。奶牛疫情和人病例数据要按CDC最新口径更新；“全球首次大规模”需要来源原文，否则改为“已知的重要奶牛群疫情”。“人传人的证据至今没有出现”改为“截至数据截止日，尚无持续人际传播证据”。

## 三、分节审核

### 第1节：年年都来的熟客
流感、普通感冒、新冠的概念边界清楚。需修正：
- 流感病毒“四个型”应说明甲、乙、丙、丁型；人类季节性流感主要涉及甲、乙型；
- “抗原转换=杂交”是通俗比喻，建议改为不同流感病毒在同一细胞中发生基因片段重配；不写成必然发生；
- “每年重新配”改为“疫苗组分通常按季节和监测结果更新”；
- 全球10亿感染和29—65万死亡必须带WHO年份和“与流感相关的呼吸系统死亡”定义；
- RSV是重要病原，不宜笼统写成所有婴幼儿和老人下呼吸道感染的“主要凶手”。

### 第2节：费城的游行
历史线成立，但需收紧：
- “主办方和许多市民都知道流感来了”需按史料限定；
- “两周杀死两千多人”必须说明是估算/报告数字、范围和起止日期；
- “整个医院病床全部告急”改为“多家医院迅速出现床位和人员压力”；
- “美国平均寿命一夜之间拉低十几年”改为“1918年相关地区平均寿命显著下降”，除非补具体研究口径；
- 不把游行单独写成费城死亡的唯一原因，应同时提到已有传播、交通、人口密集和后续公共卫生措施。

### 第3节：挖出来的病毒基因组
证据和社区伦理线有价值。需：
- “一位士兵”“阿拉斯加冻土”资料要核对样本身份与社区同意的具体范围；
- “病毒RNA片段”与1918样本保存、石蜡材料、最终基因组推断的技术历史应避免过度简化；
- “与鸟类流感基因相近”写成谱系线索，不写直接来源；
- 说明历史样本研究不等于恢复传播能力。

### 第4节：2009，以为预演过的那一次
时间线和概念边界通过。需：
- “墨西哥出现”改为“墨西哥报告并识别出相关病例/暴发”，避免首发和发现地点混为一谈；
- 15万—58万是首年全球死亡估计，实验室确诊死亡约1.8万是另一统计系统，不可并排像同一分母；
- “第二波”需注明地区和定义；
- “三重重组”按病毒学来源证据表述；
- 2009年10月疫苗铺开是多国时间线概括，不能代表所有国家；
- mRNA平台“缝合伤口”是比喻，不能暗示它已解决大流行疫苗产能和分配问题。

### 第5节：藏在感冒里的家族
七种人冠状病毒地图合理。需：
- “人类到现在一共认识七种能在人身上致病”改为“通常按七种已知可导致人类疾病的冠状病毒来概括”；
- SARS“从果子狸跳到人”改为“流行病学和动物采样支持果子狸等中间宿主参与”，保留证据层级；
- MERS病例、死亡和病死率按最新WHO/ECDC同一口径核对，不能混用；
- “蝙蝠是公认的重要天然库”改为“蝙蝠是多种冠状病毒的重要候选或已知宿主库”，不同病毒证据不同；
- ACE2是进入细胞的重要受体之一，不是所有新冠机制的完整解释；
- “越来越不稀奇”改为“跨种溢出风险受到更多关注”。

### 第6节：正在进行的这一场
这是全篇最高动态风险位置。需：
- “几周内完成基因组测序”给出具体事件和来源，不写成中国单一团队独立完成全球全部工作；
- mRNA疫苗首批授权时间可以保留，但“人类疫苗史前所未有”需改为“研发和授权速度创下重要纪录”，并承认此前平台、基础研究、临床与监管协作；
- 长新冠“一到三成”须明确人群、时间点、定义和研究范围，最好正文只保留“估计差异很大”；
- 疫苗不平等可保留，但用WHO数据，不把高收入国家和中低收入国家写成单一整体；
- 中国线需区分事实、政策评价和后续史学争议；
- 溯源句按高优先级问题修改。

### 第7节：下一个大考会是谁
收束清单合理。需：
- “H5N1头号种子”改为“重点监测对象之一”；
- 奶牛疫情、人病例、41/70数字按发布日更新；
- “新冠大概率会成为长期熟客”改为“新冠可能长期存在并持续变化，未来形态和公共卫生负担仍需观察”；
- “mRNA从几年缩到几个月”改为平台提供加速可能，实际仍取决于株型、试验、生产、审批和分配；
- “病毒没有护照，单打独斗必输”可保留作修辞，但应落回国际合作和监测证据，不作绝对结论。

## 四、结构、伦理与安全审核

### 已通过
- 七节递进清楚，1918→2009→2020的主线成立；
- 流感、SARS、MERS与SARS-CoV-2概念边界明确；
- 塔本伯格、Brevig Mission社区、测序团队和全球科研协作没有完全被单一英雄取代；
- 没有把费城游行写成单一责任主体；
- 未提供病毒重建、传播、实验或规避监管的操作信息。

### 必须保持
- 2009 H1N1不是冠状病毒；
- 历史样本基因组研究不是“复活病毒”；
- 流感死亡估计、SARS/MERS数字、新冠与H5N1动态数据都必须带口径和年份；
- 不把溯源未解问题写成阴谋论，也不写成已经封闭的定论；
- 不把疫苗、测序和抗病毒药写成万能工具。
