2. **真正拦住发布的是事实错，且多数是"本工程已经写对过、这两篇又写错了"。** 这是本轮最贵的一类病：不需要再查证，只需要回填。

## 五、B 级：读者会踩的坑

1. **"A/B/C 病原体分级"被写成"国际生物安全通用分级（CDC/WHO）"**（0_1 L71）。A/B/C 是美国 CDC 生物恐怖剂优先级，WHO 无此分级，更不是病原体危险程度通用等级。
2. **"生化科技"未定义**（61 号五.2）。它是叙事标签，不是学科；两稿导言都没交代边界，读者会以为涵盖全部生命科学。
3. **"百年"与实际跨度不符。** 0_1 标 1880s—2026（146 年）、0_2 标 1915—2026（111 年）却都叫"百年"。
4. **"四道门槛""四代演进"是自创分类**，无学界采用；用就须说明是本文分析框架。
5. **"编年"名不副实**：0_1 下编第六章、第七章不是逐年编排，是阶段概述。
6. **0_1 第八章"史料方法论"是编辑内部方法**，应移出正文（61 号五.1）。
7. **"2026 年的历史回顾依然将德特里克堡列为源头"**（0_2 L171）——空来源，等于没说。
8. **全篇 22 个单元（0_1 十章、0_2 序章＋八章＋结语＋两附表），0 个带 `## 资料来源与核实说明`，0 条给出档案号、报告名或发布日期。** "证据层级注解"是等级标签，不是来源。这是两稿最系统的一处不合规。
