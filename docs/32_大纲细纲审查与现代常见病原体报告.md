# 《毒与证》大纲与细纲审查暨现代常见病原体系统报告

> 审查日期：2026-09-14  
> 审查对象：`01_系列大纲.md`、`14_系列逐节细纲与知识路线.md`、`31_大纲与细纲_病原体科普完备性评估报告.md`、`00_项目协议.md`及相关素材库。  
> 本报告是编辑与知识架构审查，不替代临床指南；当代负担数字必须在正式发布前按同一数据截点重新核验。

## 一、执行摘要

### 结论

现有路线**作为“病原体—证据—生物安全—公共卫生”代表性系列，主干已经成立；作为“现代常见病原体系统地图”，尚未足够完备**。此前“85%–90%完备”的判断需要降格理解：它更接近“核心历史案例覆盖度”，而不是按当代疾病负担、常见程度和防治决策建立的全景地图。

主要原因有三类：

1. **覆盖偏向高历史戏剧性和生物安全关联**：炭疽、鼠疫、天花、埃博拉、731等很强，但普通人更常遇到的麻疹、呼吸道合胞病毒、诺如病毒、肺炎链球菌、幽门螺杆菌、真菌感染、耐药菌等没有相称位置。
2. **结构编号和路线已经发生漂移**：总纲标题、发表顺序、总览表、细纲物理顺序和终章回收清单不再使用同一套篇号。
3. **“发现团体/攻克团队”与证据审计模板不足**：多处把复杂的团队、社区、样本提供者、患者和公共卫生系统压缩成一个英雄人物；这会同时造成事实风险和叙事伦理问题。

### 建议的总判断

- **保留现有历史主线**，不要把系列改成百科全书。
- 明确增加一个“现代常见病原体地图/总账”层，采用“总表 + 五类分表 + 横向专题”。
- 将**乙肝、幽门螺杆菌、肺炎链球菌、呼吸道合胞病毒、诺如病毒、麻疹、真菌、血吸虫、AMR**列为第一批补强对象；狂犬病与登革热已立项，应冻结为正式篇，不再停留在候选状态。
- 在任何重排前，先冻结唯一篇号，再全库替换和验收。

## 二、现有大纲的系统性优点

1. 已建立“病原体/毒物、感染/发病、相关/因果、风险/现实概率”的概念边界。
2. 有“制度篇—病原体列传—横向感染—生物安全—治理—成瘾公共卫生”的纵向叙事潜力。
3. 对朊病毒、耐药、疫苗局限、实验室安全、证据等级和不确定性已有意识。
4. 已设置希望出口和安全红线，避免把病原体科普写成恐怖故事或攻击指南。
5. 中国线并非只写苦难，也包含伍连德、高守一、顾方舟、屠呦呦等公共卫生与医学成就。

这些优点应保留，但要从“写作纪律”升级为可验收的数据结构。

## 三、现代常见病原体覆盖审查

### 1. 当前已形成的核心层

| 类型 | 现有重点 | 判断 |
|---|---|---|
| 细菌 | 炭疽、鼠疫、结核、霍乱 | 历史与生物安全强；社区常见菌和耐药菌不足 |
| 病毒 | 天花、埃博拉、流感、新冠、脊灰、HIV、肝炎、狂犬病/登革热 | 大流行与消除史强；儿童常见呼吸道、胃肠道病毒不足 |
| 寄生虫 | 疟原虫，血吸虫点名 | 疟疾完整；蠕虫、原虫、食源/水源寄生虫不足 |
| 真菌 | 番外点名 | 明显不足，不能仅作为“脚气/灰指甲”远亲带过 |
| 朊病毒 | 库鲁、BSE、vCJD、CWD | 已有独特深挖框架，但需强化社区主体和病例分类 |

### 2. 第一优先级补入对象

| 病原体/群 | 为什么必须补 | 推荐形式 |
|---|---|---|
| 乙型肝炎病毒 | 中国慢性感染、肝硬化与肝癌负担大；母婴传播、疫苗和长期治疗具有独特对照价值 | 将现有第13篇冻结为独立篇，不只放在STI比较段 |
| 肺炎链球菌 | 儿童肺炎、老年和免疫低下人群重症；疫苗与耐药并存 | 病原体总账专题或细菌横断节 |
| 幽门螺杆菌 | 常见慢性感染，胃炎、消化性溃疡和胃癌风险；根除与耐药需要风险分层 | 细菌横断专题 |
| 呼吸道合胞病毒 | 婴幼儿和老年人重要呼吸道负担；预防工具近年变化快 | 病毒横断专题 |
| 麻疹/风疹/腮腺炎 | 疫苗可预防病的典型；群体免疫与免疫空白是系列核心议题 | 疫苗可预防病专题 |
| 诺如/轮状病毒 | 普通人高频胃肠道感染；传播、环境控制和疫苗边界清楚 | 水源/食源和儿童感染专题 |
| 真菌：皮肤癣菌、念珠菌、曲霉、隐球菌、耳念珠菌 | 现有体系几乎没有真菌科学；需要解释机会性感染和抗真菌耐药 | 新增真菌横向专题，必要时独立篇 |
| 血吸虫、弓形虫、贾第鞭毛虫、隐孢子虫 | 生活史、动物宿主、食源/水源和孕期风险可补足寄生虫地图 | 寄生虫横向专题 |
| AMR | 不是一种病原体，而是跨细菌、真菌和部分病毒/寄生虫的系统性风险 | 独立横向专题，不能只在结核和淋病中零散提及 |

### 3. 第二优先级候选池

- 细菌：脑膜炎奈瑟菌、百日咳鲍特菌、金黄色葡萄球菌及耐甲氧西林金黄色葡萄球菌、大肠杆菌致病型、沙门氏菌、弯曲菌。
- 病毒：普通人冠状病毒、诺如病毒、轮状病毒、乙脑、黄热、寨卡、西尼罗、尼帕、麻疹和风疹病毒。
- 真菌：毛霉菌、组织胞浆菌等区域性或免疫缺陷相关病原体。
- 寄生虫：利什曼原虫、淋巴丝虫、盘尾丝虫、蛔虫、钩虫、蛲虫、华支睾吸虫。

这些不必全部写成独立篇，但必须在总账中给出“覆盖级别”和“不单独展开的理由”。

## 四、现代常见病原体报告：建议的统一数据卡

“发现团体”不能只填一个姓名。建议把发现拆为六个角色：

1. **疾病首次描述**：最早病例、临床识别或历史记录。
2. **病原体首次观察/分离**：谁在什么材料中看见、培养或检测到。
3. **致病因果建立**：实验、流行病学、分子证据和反复验证由谁完成。
4. **传播机制和诊断建立**：媒介、受体、血清学、分子检测等团队。
5. **治疗/疫苗/暴露后预防突破**：研发团队、临床试验、生产和监管体系。
6. **控制或消除团队**：监测网、基层医务人员、患者/社区、国际组织和政策系统。

每个条目固定填写：

- 标准中文名、学名、类型、主要型别/血清型/耐药型；
- 宿主、储存宿主、媒介和传播途径；
- 潜伏期、无症状感染、慢性化、环境持留和动物源性溢出；
- 典型综合征、重症人群、长期后果、孕产妇/儿童影响；
- 诊断窗口和常见误区；
- 疫苗、特异治疗、抗毒素/免疫球蛋白、暴露后处置；
- 全球与中国当代负担：年份、地区、病例定义、发病/死亡/慢性感染/DALY口径；
- 耐药、免疫逃逸和防治限制；
- 普通人可做什么、何时就医、不得自行做什么；
- 证据等级、争议、数据截止日期和下一次复核日期。

### 五类分表建议

#### A. 细菌

首批：结核分枝杆菌、肺炎链球菌、幽门螺杆菌、金黄色葡萄球菌/耐甲氧西林株、大肠杆菌致病型、沙门氏菌/伤寒、副溶血性弧菌、霍乱弧菌、脑膜炎奈瑟菌、百日咳鲍特菌、淋病奈瑟菌、梅毒螺旋体；炭疽和鼠疫保留为历史/生物安全深度案例。

固定强调：无症状携带、毒素介导疾病、慢性感染、耐药、抗生素并非“消炎药”的同义词。

#### B. 病毒

按呼吸道、血液/性传播、肠道、媒介/动物源、神经嗜性和可消除性分组。首批应包括流感病毒、SARS-CoV-2、普通人冠状病毒、呼吸道合胞病毒、麻疹病毒、乙肝病毒、丙肝病毒、HPV、HIV、诺如病毒、轮状病毒、狂犬病病毒、登革病毒、乙脑和脊灰病毒；天花、埃博拉、马尔堡、猴痘作为消除/暴发/生物安全案例。

#### C. 真菌

至少纳入皮肤癣菌、念珠菌、耳念珠菌、曲霉、隐球菌和肺孢子菌。固定强调：宿主免疫状态、环境暴露、侵袭性死亡风险、诊断延迟和抗真菌耐药。

#### D. 寄生虫

至少纳入疟原虫、血吸虫、利什曼原虫、淋巴丝虫/盘尾丝虫、弓形虫、贾第鞭毛虫、隐孢子虫以及常见土源性蠕虫。必须区分“感染人数”“有症状病例”和“重症病例”，并画出生活史与中间宿主。

#### E. 朊病毒

采用独立框架：病例识别—病因假说—朊病毒命名—传播与控制。分开散发、遗传、医源性、动物源性四类；CWD必须写“目前没有确认的人类病例”，同时说明持续监测并不等于零风险证明。

## 五、现有大纲的逻辑与系统性Bug

### 高优先级：动笔前必须修

1. **篇号冻结失败**：`01`标题写“番外2节+18篇”，正文和顺序延伸到第20篇；`14`先列第15/16篇，再回到第12–14篇。Biopreparat、731、BWC、合成生物、化学武器、毒品在不同文件中反复漂移。
2. **收束清单漏项**：部分终章只回收到篇16或17，无法稳定覆盖化学武器、毒品与成瘾篇。
3. **覆盖声明与实际路线冲突**：一处把“武器化病原体”写成12–14篇，另一处实际对应Biopreparat/731及后续治理线；化学毒物和自伤性毒物的篇号也发生错位。
4. **发现/攻克个人化**：Meselson、Waksman、Taubenberger、屠呦呦、伍连德、顾方舟、Piot都需要加协作者、样本提供者、患者/社区和公共卫生系统，避免把团队成果写成个人独立完成。
5. **存在高风险事实表述**：高守一与O139的关系必须改为中国监测/流调贡献，不能直接写“发现者”；福谢与Kawaoka两条研究线要并列；731与美国、德国之间的“成果流入”必须逐条区分档案事实、研究者推断和未证实连接。
6. **医学行动表述需改写**：狂犬病免疫球蛋白应写“暴露后尽快处理，通常在首剂疫苗当天给予；部分指南允许在首剂后一定窗口内补用”，不能写成“可等7天”。
7. **新冠与SARS溯源不能写成终局结论**：需给报告日期、证据等级和不确定性；“果子狸→人”应改为证据支持的中间宿主线索，而非无条件单箭头。

### 中优先级：立项与审稿时修

- 麻疹、风疹、腮腺炎、RSV、诺如/轮状病毒、肺炎链球菌、幽门螺杆菌、AMR、真菌和寄生虫覆盖明显不足。
- HBV篇主角尚未冻结；且围产期与成人感染的慢性化风险不能用一个比例概括。
- 朊病毒篇应加入当地医生、人类学者、Fore社区主体，避免“从巫术中发现真相”的单线猎奇叙事。
- “詹纳=第一支疫苗”应限定为现代疫苗史中的首个成功范例，区分更早的种痘实践。
- “顾方舟让自己孩子先试服”“屠呦呦自己试药”“一个口罩灭疫”等传播力强的句子必须逐条核原始材料，改成可证实的行为与团队证据。
- 同一素材要登记“唯一主责篇、次引用篇、不同侧重点”，尤其是1894香港、SARS、鼠疫武器化、毒素/BWC。

## 七、编辑验收清单

发布一篇前，编辑应能回答：

- 这一篇的主病原体是谁，是否与其他篇有唯一主责关系？
- “发现者”究竟指首次观察、分离、命名还是因果证明？
- “攻克团队”是否包含临床试验、生产、监管、基层和患者/社区？
- 每个数字是否有年份、地区、病例定义和来源？
- 是否把感染、发病、重症、死亡和长期后果混成一个数？
- 是否把有疫苗写成已消灭、把有药写成容易治疗？
- 是否给出普通人安全行动，同时明确不自诊、不自行用药？
- 是否把争议写成争议，把未证实内容留在存疑备注？
- 是否完成篇间去重、术语、链接、数据截止日期和敏感内容审读？
