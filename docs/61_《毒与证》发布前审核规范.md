# 《毒与证》发布前审核规范

> 版本：1.0.3.0
> 用途：统一审核性传播感染及全系列后续稿件的事实、医学、安全、语言和发布格式。
> 原则参考：ASD-ST100式写作原则；要求短句、术语稳定、责任主体清楚、条件与例外不遗漏。

## 一、审核顺序

每篇按以下顺序审核：

1. 先读工作纪律和当前正文，不凭旧稿或提纲替代新稿。
2. 确认文章范围：篇名、节数、读者对象、是否涉及医疗行动建议。
3. 做事实审核：人物、时间、数字、因果关系、法律和政策状态。
4. 做医学与安全审核：诊断边界、就医建议、药物和急救边界、生物安全边界。
5. 做结构和语言审核：语序、短句、术语一致、段落逻辑和读者可读性。
6. 清理发布稿元数据：删除内部审核、写作过程、资料卡、红线、草稿状态和待核提示。
7. 写入审核记录：记录问题、修改建议、篇级结论和下一步。
8. 保存并提交交付文件。

## 二、事实和证据规范

### 0. 两条总原则

1. **确保有据可查**：正文里的每一个数字、日期、人名、机构、法律状态，都要能在同篇资料说明或公开权威来源里找到对应条目。找不到对应来源的，删掉；确实重要但来源不足的，写明"资料不足"或"目前无法确认"。
2. **逻辑通顺、言语简洁**：一段只走一步，一句只承担一个判断；能短句就不写长句；删掉不推进论述的句子和形容词。

这两条优先于其他细则：与后文冲突时，以能查证、能读懂为准。

### 1. 事实分层

正文必须区分：

- 直接事实：有原始档案、条约原文、官方报告或正式论文支持。
- 研究结论：有多项研究或权威综述支持。
- 估计：写明范围、年份、统计对象和来源。
- 争议：并列主要解释，不把一种解释写成定论。
- 未知：明确写“目前无法确认”或“资料不足”。

### 2. 数字写法

每个数字至少保留年份或统计截止日期、地区或统计范围、统计对象，以及报告、估计、模型或抽样性质。不同年龄组、年份和指标不能拼成一个因果句。

### 3. 因果关系

“导致”“造成”“证明”“唯一原因”“直接起点”等词需要证据支持。证据不足时改为“与……相关”“可能促成”“被研究者认为”“是其中一个因素”或“现有资料支持……，但不能据此证明……”。

### 4. 术语解释的取舍

一条判据：**这个词是否承担一个因果。**

- 承担因果的，解释；不承担因果的，删掉，或者不解释。
- 解释的内容是“它带来什么后果”，不是词典定义。读者不需要知道 RNA 的全称，需要知道“RNA 病毒变异快，所以丙肝没有疫苗”。
- 解释放在框架节，不在叙事节第一次遇到时插一段。一次交代，后文指回，全书只解释一次。
- 解释的长度由因果的长度决定：一句话能说清就一句话，三句话说清就三句。收益是读者多懂一个因果，成本是打断一次节奏。
- 不做术语表，不做脚注（nicemd 转 HTML 后阅读体验差），缩写不堆英文全称。

四类处理：

| 类别 | 判断 | 例子（第 13 篇） |
| --- | --- | --- |
| 承担论证 | 解释后果 | RNA 与 DNA：RNA 复制易出错所以丙肝没有疫苗，DNA 能在细胞核留副本所以乙肝难根治 |
| 影响行动 | 解释差别 | 免疫球蛋白与疫苗：一个打进去立刻有抗体，一个要等身体自己产生 |
| 读者会误认 | 半句纠正 | 免疫球蛋白容易被当成“补品”；甲胎蛋白容易被当成肝功能的另一项 |
| 纯学术修饰 | 删 | “单股正链 RNA 病毒”里的“正链”，删掉不影响任何理解 |

反例也要留：`HBV DNA 定量` 不解释。读者只需要知道“查病毒有多少”，不需要知道定量怎么做。

### 5. 篇幅

单节 900—1,200 字是 2026 年上半年的规矩，目的是迁就微信阅读。**2026-10 起放开**：生化卷与后续各卷以讲透为准，建议 1,200—2,200 字，超过 2,500 字再考虑拆节。病原体卷已发布的部分不改。

判断"该不该长"的标准不是字数，是**这一节有没有第二层内容**：如果只是把话说得更细，压缩；如果多出来的是"为什么是这样"的链条，留着。

## 三、医学、公共卫生与安全规范

### 1. 诊断和治疗边界

- 不把症状描述写成诊断工具。
- 不给个人开药、给剂量或安排疗程。
- 不把一般科普写成个体化医疗建议。
- 明确何时联系医生、急诊、疾控或其他正规机构。
- 需要专业判断的内容，写明责任主体是医生、急救人员或主管机构。

### 2. 传播和风险

区分感染、发病、携带、暴露、传播风险和确诊。不把“可能”写成“必然”，不把“不传播”扩大到所有情境，也不把一个病种的疫苗、PEP、PrEP、药物或隔离逻辑套到另一病种。

### 3. 急救和现场建议

读者建议按以下顺序写：先离开危险；呼叫急救或主管机构；不让未经防护者进入危险区域；只写公众能够安全执行的动作；药物、去污、复苏等专业操作交给受训人员。

### 4. 双重用途和危险信息

不得提供病原体或毒剂的培养、扩增、合成、改造和投放步骤，剂量、配方、序列、设备参数、操作条件，以及规避检测、监管或核查的方法。可以保留历史背景、非操作性风险解释、法律公约伦理治理和公众撤离求助原则。

## 四、语言和去AI味规范

### 1. 自然中文

- 优先使用主动句，明确谁做什么。
- 避免连续使用“这不是……而是……”。
- 避免句式整齐到像提纲。
- 长句拆成两到三句。
- 一段只承担一个主要动作或判断。
- 少用抽象名词堆叠，多用具体动词。
- 少用“赋能、闭环、抓手、路径、锚点、底座、窗口期、机制性”等翻译腔或公文词；确有必要时才保留。
- 少用“我们看到、值得注意、必须指出、归根结底、从这个意义上说”等套话。

### 2. 同一概念只用一个名称

首次出现写中文全称（英文全称，缩写），后文固定使用中文或约定俗成缩写。例如：性传播感染（sexually transmitted infections，STI）、暴露后预防（post-exposure prophylaxis，PEP）、暴露前预防（pre-exposure prophylaxis，PrEP）。不要交替使用会改变含义的称呼。

### 3. 去除过度修辞

少用“最、第一、唯一、彻底、永远、零风险、万能”等绝对词。标题可以有修辞，但正文第一段必须给出科学限定。不把苦难、患者和受害者写成猎奇景观。

### 4. 反污名

不把感染、成瘾、性行为、贫困或犯罪归结为道德品质。不用“危险人群”替代具体暴露情境。不把国家、地区或族群写成病原体或毒品的道德来源。讨论责任时，同时保留治疗权利、隐私和求助渠道。

## 五、正文与资料说明的元数据清理

### 1. 正文必须删除

“待核”“发布前核对”“以最新数据为准”“红线”“大纲要求”“本篇写作纪律”“作者注”“审核意见”“证据卡要求”“见内部记录”“下篇待写”“本系列方法论要求”，以及版本号、发布日期、工作备注和补来源占位句。

### 2. 资料说明可以保留

资料说明只写读者需要知道的来源和限制：来源机构、作者、论文、报告或法律文本；数据年份、统计口径和适用范围；争议事实的证据性质；医疗和法律信息的适用边界。不得把阶段性审核记录、内部红线和本系列纪律当作读者版来源。

### 3. 互引规范

优先写“篇名＋节名”，其次写“篇号＋篇名”。不写只有编辑知道的“见第X节”。未完成或未发布的篇目，不在正文中写成已存在的读者链接。每次修改后重新检查篇号、标题和链接指向。

## 六、性传播感染篇专用检查表

### 医学内容

- 不把感染等同于发病。
- 区分性接触、血液、母婴和皮肤密切接触。
- 说明无症状感染和检测窗口。
- 不凭症状、外观、婚姻或伴侣数量诊断。
- 分别核对梅毒分期、淋病耐药、衣原体、生殖道支原体、HPV、疱疹和滴虫。
- HIV、乙肝和丙肝只作比较，不互相套用治疗或预防方案。
- U=U、PrEP、PEP以当前指南和专业评估为边界。
- 不提供自行用药、剂量、疗程或规避检测建议。

### 语言内容

优先使用“性传播感染”，不把感染者写成道德对象。不使用“脏、乱、滥交、危险人群”等污名化词。不把伴侣通知写成强制曝光。不写露骨性行为细节。行动建议指向检测、正规就医、隐私保护和支持渠道。

### 发布结构

每节检查四件事：读者能否在第一段知道主题；事实、解释和行动建议是否分开；读者能否看出确定事实、研究结论和争议；资料说明是否已去掉内部审核语句。

## 七、审核记录格式

每篇审核记录至少包括：审核对象和版本；总体结论；逐节问题；医学、事实和安全边界；语言与发布化问题；发布前最小清单；是否需要第二轮复审。

篇级结论只使用四类：无需重写；有条件通过；暂缓终审；暂缓处理。

## 八、交付规则

- 不删除原稿；删除指令按工作纪律移动到 .trash。
- 同名新文件不覆盖，使用版本号。
- 临时文件、代码和日志放入工程 tmp 目录。
- 修改或新增审核记录后，必须提交文件并在回复中给出可点击路径。
- 正文有修改时，同时提交所有修改过的正文文件。
- 最终回复只报告已完成事项、关键问题和下一步，不重复整篇正文。
