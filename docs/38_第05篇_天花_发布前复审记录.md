# 第5篇《天花》发布前复审记录（2026-09-16）

> 审核对象：正文/待发_天花篇01—07；参考 docs/36、docs/37、docs/33、docs/14。
> 本次复审重点：根除史、疫苗史、实验室样本、生物安全、猴痘动态信息和绝对化表述。

## 一、总体判定

**篇级判定：有条件通过，但不建议原样发布；完成下列定点修订并更新猴痘动态资料后，进入作者终审。**

七节结构成立：看不见的病毒 → 詹纳与牛痘 → 根除条件 → 全球最后一战 → 伯明翰事故 → 样本保存与治理 → 正痘家族和猴痘。人物线、知识线和“证据证明根除”的收束清楚，未发现需要重构的问题。

## 二、高优先级修订

### 1. “四张牌”不能写成天花根除的唯一充分解释
专一宿主、症状可识别、疫苗和全球协作是有效解释框架，但根除还依赖监测—围堵、病例发现、基层卫生人员、地方社区参与、冷战时期国际合作、疫苗供应和认证机制。建议把“天花恰好四张全齐”“缺一张游戏就玩不下去”改为“这些条件共同降低了根除难度，但并非单独充分条件”。

### 2. “无症状传播/出疹前传染性很低”需保留自然史边界
天花在出疹前通常传播性较低、出疹后更易识别，但不能写成绝对没有隐匿或出疹前传播。建议把“古往今来没有一种天花是无声的”“几乎等于自己挂着我是传染源的牌子”改为文学比喻后立即收回：症状明显有助于发现和隔离，但不能替代监测。

### 3. 第6节涉及重建近似病毒的句子建议删除
“今天的实验可以用基因工程重建近似天花病毒的模型”对读者没有必要，且会把篇章带向危险技术想象。改为：
> 研究者可以利用非复制性模型、替代系统和其他经批准的安全平台评估检测、疫苗和药物；具体技术不在本文展开。
不要出现重建、合成或近似天花病毒的技术暗示。

### 4. 样本保留与药物研发不能写成单线因果
第6节“tecovirimat就是靠保留样本那段时期研发出来的”证据不足且容易误导。建议改为：
> 样本保留和生物安全准备为相关研究提供了制度背景；tecovirimat属于面向天花等正痘病毒风险开发的储备药物，其对真实天花患者的临床有效性不能用现有临床试验直接证明。

“两座冰柜”应明确为WHO认可的两个保藏机构/参考实验室，不写成全人类样本必然只有两处。库存数量也应保留来源和时间截点。

### 5. 猴痘部分必须发布前更新
第7节的数据截至2024年8月，发布前必须更新：
- WHO最新PHEIC状态和疫情报告；
- 分支和传播趋势的最新表述；
- MVA-BN/JYNNEOS适用人群、剂次和保护证据；
- tecovirimat的监管状态和临床证据边界。
“全球重大疫情”“只能控制、不能根除”“这是病毒生物学决定的”均应收紧为“目前尚无根除条件/公共卫生目标是控制传播和降低重症”，不要把现实政策判断写成永久生物学结论。

## 三、分节审核

### 第1节：看不见的凶手
病毒概念、伊万诺夫斯基—贝杰林克—电子显微镜—天花病毒的路线清楚。需注意：“第一次真正看见”是传播性叙事，不宜当作严格发现史；“只感染人类”应写“自然宿主目前仅知为人类”；大天花/小天花病死率须保留历史条件和来源；“在没有疫苗时代几乎人人难逃”建议改为“许多人会在一生中暴露或感染”，避免无来源的全人群断言。

### 第2节：挤奶女工的手
詹纳、Sarah Nelmes、James Phipps和1798论文线通过。需核对“人痘接种传入中国”和牛痘法传入中国的日期，不要把詹纳写成第一个疫苗思想者；“牛痘病毒”与疫苗病毒的历史关系应避免简单等同。tecovirimat段要加“用于储备/正痘病毒风险，不能把预防和治疗天花写成已被临床充分验证”。

### 第3节：凭什么它能被消灭
四条件框架有传播力，但需补全球卫生团队、监测和社区参与。
- “一针管好多年”“不需要冷链”应改为按历史疫苗制剂和项目条件限定；
- “巴西、印尼、西非的战绩证明这一招”改为“相关项目经验支持这一策略”；
- “一出疹子就容易被认出来”应保留鉴别诊断和早期症状不典型的边界；
- 麻疹R0和95%覆盖率数字必须带来源、定义和年份，或改为定性比较。

### 第4节：最后一战
全球根除主线通过。
- “1979年7月”按36号记录建议改为“1979年”，除非补入WHO档案月份来源；
- Rahima Banu应写“最后重型自然病例”，Ali Maalin写“最后记录的自然感染病例”，两者不要混为“最后一个天花病例”；
- “全世界十万多名调查员”需保留来源和口径；
- “病毒在火苗里烧死”“人肉搜索”等比喻可保留，但不要削弱当地卫生人员、社区和行政系统的贡献；
- 中国“60年代初扑灭”的年份差异应并列说明，不做“总之”式抹平。

### 第5节：最后一个逝者
帕克死亡日期和入院时间线已按36号记录修正。
- “病毒沿管道气流漏上去”应继续写成调查推断，不写成完全确定的物理路径；
- “英国彻底关停天花研究”需限定为相关实验室/相关研究，避免国家层面的过宽概括；
- 贝德森自杀和责任归因应以调查史料为准，不写成单一个人承担全部制度责任。

### 第6节：两座冰柜里的病毒
样本保存争论与2014 NIH样品事件有价值。
- 删除或改写基因工程重建近似病毒的句子；
- “全部加起来”改为“公开确认的主要保藏点”；
- “保留样本促成tecovirimat”改为制度背景和风险准备的间接关系；
- “双人核对、定期清点”可以作为治理原则，但不要暗示这是某次事故后唯一或完整的制度答案。

### 第7节：正痘家族的近亲
作为天花收束合理，但它是动态医学内容，必须最后更新。
- “猴痘病毒”与WHO推荐名称、中文译名按发布日核对；
- 2022年传播网络应避免把性接触写成病原体固有属性，补充皮肤接触、口鼻分泌物、家庭和照护场景；
- “疫苗保护力和持久性不如当年天花疫苗”需要来源，否则改为“保护效果、剂次和持续时间需按疫苗产品与最新证据判断”；
- tecovirimat不是面向普通人自行使用的处方建议；
- 分支I与IIb病死率比较必须补WHO原文或删除定量暗示。

## 四、结构、伦理与安全审核

### 已通过
- 七节递进成立；
- 詹纳、WHO团队、地方卫生人员、社区和实验室制度没有完全被单一英雄取代；
- 帕克事件没有污名化患者；
- 猴痘部分具有预防和监测出口；
- 未提供天花培养、扩散、攻击剂量、合成或规避监管的操作信息。

### 必须保持
- “根除”与“消灭/地区消除”概念区分；
- “最后一例”必须注明最后重型、最后自然感染或最后死亡的具体含义；
- 天花根除不等于样本风险为零；
- 猴痘现行疫情、疫苗和药物表述不能沿用固定旧数据。
