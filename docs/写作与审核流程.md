# 写作与审核流程

日期：2026-10-12（v2，按"缺陷—追问—规则"重写）

## 一、三个角色

| 角色 | 是谁 | 职责 |
| --- | --- | --- |
| 主笔 | 当前会话 | 收集证据、写作、判断哪条意见必须改、把追问结果写成规则 |
| 审核员 | 独立会话，同一模型，不共享写作上下文 | 只做三件事：分类、计数、指认位置。不改稿，不给"更好的写法" |
| 作者 | 用户 | 终审、发布决定 |

审核员必须是"外人"：它没有主笔的推理过程，只看到稿件。主笔自己审自己，会漏掉自己已经想通但没写出来的地方。

## 二、两个计量单位：缺陷与轮次

这是 v1 最大的错误：拿"轮次"当质量尺子，等于用深度工具量宽度。

- **缺陷**是横向的：一篇稿子里有很多互相独立的问题。
- **追问**是纵向的：一个问题往下挖五层，挖到根因。

所以：

- 对**单个缺陷**，用五步追问（第三节），深度上限五层。
- 对**整篇稿件**，用净流入判定收敛（第五节），不数轮次。

轮次多不说明认真，只说明规则没生效。

## 三、五步追问：对缺陷用，不对稿件用

### 1. 它是什么

一个问题连问五次"为什么"，从现象挖到根因。挖到第五层时，得到的通常不是"改这一处"，而是"改一条规则"。

它对付的是三类东西：想当然、幻觉、把巧合当因果。对写作者尤其有用——因为作者最容易被自己的推理说服。

### 2. 一个真实例子（本卷总篇 07 那张表）

> 现象：表里德国"高峰"写成"二战期间的生物破坏活动"。

1. 为什么错？凭印象把一战的事写成了二战。
2. 为什么凭印象？表是手写的，正文与表之间没有映射。
3. 为什么没有映射？表在正文写之前就定稿了。
4. 为什么先定稿？把它当"导航工具"，没当"正文的摘要"。
5. 为什么允许两者不同步？流程里没有回填检查、没有校验脚本。

第五层给出的不是"改这一格"，是**"表格必须从正文校验，不能凭印象"**。这条规则一立，同一轮里中国行起点与高峰倒置、苏联行缺年份、伊拉克行丢掉"化学"两个字，全部一起扫掉。

### 3. 使用边界

- 只对 A 级缺陷和"反复出现的类型"做完整五层。B、C 级不必挖这么深，改掉即可。
- 五层挖不到根因，说明问题在证据层（不知道事实是什么），不是逻辑层——回到查证，不要继续追问。
- 追问的产出必须落成一句可执行的规则，写进回填清单（第六节）。没落成规则的追问，等于没问。

## 四、三段式流程（替代"反复审稿"）

### 第一段：广度（一次性全文）

审核员全文读一遍，只交一张**缺陷总表**，按类型聚类，不逐条改。

要求：

- 每条给位置和原句片段；
- 每类给计数（"年份漂移 6 处""表格不同步 4 处"）；
- 分级只按一件事：读者会不会踩坑。

主笔这一段的动作是**分类，不是修**。

### 第二段：深度（逐类追问，出规则）

对缺陷总表里的每一类做五步追问，得到规则。产出形如：

- 表格从正文校验，不手写；
- 改年份必须同时查小标题、表格、资料条目、收尾复述句；
- 删除一段必须查孤儿资料条目与悬空指代。

然后**批量修同类**——不是逐条修。同一类病一次改完，改的时候按规则扫全篇。

### 第三段：验证（只审增量）

审核员只读**改动处与回填点**，不重读全文。报三类：新增、复发、未修。

这一段成本从"十分钟"降到"两分钟"，而且同类问题不会重新长出来。

## 五、收敛判定：净流入

不数轮次，算这个：

> **净流入 = 本轮新发现的 A/B 级 − 本轮修复造成的 A/B 级**

| 净流入 | 含义 | 动作 |
| --- | --- | --- |
| > 0 | 还在恶化，或者修复本身在制造问题 | 先查方法，不急着改 |
| = 0 | 打平 | 可以收 |
| < 0 | 修复造成的比修掉的还多 | **立刻停**，说明动手方式有问题 |

四条即时停手信号：

1. A 级清零，且 B 级只剩同一类型 → 收。
2. 同一类问题第二轮复发 → 停。这不是稿子的问题，是流程缺一条规则。
3. 一轮耗时超过十分钟，且没有新增证据类发现 → 停，在措辞层面打转。
4. 一轮里两条以上 A 级是上一轮改动造成的 → 停，回去补规则。

## 六、回填检查（每轮改完必做）

改动从来不是孤立的。本卷反复出现的失败模式是"正文改对了，周边没跟上"。

| 改动类型 | 必须回填的地方 |
| --- | --- |
| 年份 / 日期 | 小标题、表格对应格、资料条目、收尾的复述句 |
| 地点 / 机构名 | 首次出现处、表格、其他篇的引用、资料条目 |
| 术语或译名 | 全篇所有出现处，以及跨篇首次出现处 |
| 数字 / 口径 | 表格、事实边界、资料条目、其他篇的同一数字 |
| 新增一段 | 前后衔接、本节小标题是否还成立、本节长度是否失衡 |
| 删除一段 | 是否留下孤儿资料条目、悬空指代（"前一份""后者"） |

一句话：**改一处，查三处**——同一篇的别处、表格里、别篇里。

硬要求：**每轮结束至少新增一条回填规则**，否则这一轮不算完成。

## 七、主笔的回应规则：不是每条意见都必须改

拿到审核意见，先判断，再动手。**判断的尺子只有一把：读者。**

### 1. 三条判断顺序

1. **读者会不会卡住？** 读不懂的名词、读不通的句子、被误导的因果、对不上的年份——是隐患，改。
2. **改完会不会引入新错？** 要动的地方有没有回填点？有，先列清单再改；没把握的，宁可不改。
3. **不改的代价是什么？** 留下的是"读者会踩的坑"，还是只是"不够漂亮"？前者改，后者不改。

### 2. 分级不等于命令

- A 级（事实错、口径混、逻辑断、违红线）：改。
- B 级（读者会卡住）：改。标准是"非专业读者会不会停下来"，不是"审核员觉得该有"。
- C 级（体例）：改，成本低。
- D 级（结构、措辞、偏好）：可以不改，写明理由。

### 3. 为了满足审核而改，本身就是风险

本卷出过实例：审核员说收尾"战后却没有被审判"与伯力审判冲突，主笔改成"受审的是 12 名中下级军官"——把关东军总司令写成了下级军官，新错比旧错更硬。

**修 A 时挖出来的新坑，比原来的 A 更难发现。** 所以改之前先想"这句话改完，还有哪些地方要跟着动"。

### 4. 分歧怎么处理

审核意见与证据冲突时，以证据为准；审核意见与"读者是否需要"冲突时，以读者为准。两种分歧都写进记录，一句话说明为什么不改。

## 十、为什么这样分工

主笔的问题不是不会写，是写的时候已经替读者想过了——想过的部分就不写。审核员没有这个过程，它读到的就是读者读到的。它卡住的地方，读者也会卡住。

流程的问题不是不认真，是把"改得多"当成了"改得好"。真正让稿子收敛的不是第五轮、第六轮，是第二段挖出来的那几条规则。
